# 던전 슬레이브

[Releases](https://github.com/qmfleh/dungeon-slave-play/releases)에서 최신 `DungeonSlave.zip`을 받아 압축을 풀고 `DungeonSlave.exe`를 실행하세요.

- `DungeonSlave.exe`와 `DungeonSlave.pck`는 같은 폴더에 있어야 합니다.
- 게임을 켤 때 새 버전이 있으면 자동으로 받아서 적용합니다.
- Program Files처럼 쓰기 권한이 없는 폴더에 두면 자동 업데이트가 안 됩니다. 바탕 화면이나 다운로드 폴더에 풀어 주세요.
